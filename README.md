This is an Operating Systems mini-project developed using Python. It simulates three CPU scheduling algorithms: FCFS, SJF, and Round Robin.

Features
First Come First Serve (FCFS)
Shortest Job First (SJF)
Round Robin (RR)
Waiting time calculation
Turnaround time calculation
Average waiting and turnaround time
Technologies
Python
Visual Studio Code
GitHub
Requirements

Python 3.10 or later is recommended. No external libraries are required.

How to Run
Download or clone this repository.
Open the project folder in VS Code.
Open the terminal.
Run:
python cpu_scheduler.py

On Windows, you can also run:

py cpu_scheduler.py
Enter the process burst times.
Choose a scheduling algorithm.
Assumptions
All processes arrive at time zero.
Burst times must be positive.
SJF is non-preemptive.
Round Robin uses a positive time quantum.
Conclusion

This project demonstrates how different CPU scheduling algorithms work and how they affect waiting time and turnaround time.
